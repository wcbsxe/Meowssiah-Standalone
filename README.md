## 功能

保留原预设请求改写、工具、签名字段和输出处理，日志上传关闭。独立宿主提供世界书总库、角色卡独立选书、MVU 变量、EJS 模板、聊天管理和分页界面。

## 单步回撤与修改输入

- 输入区右边的“撤回本轮”恢复最近一次发送或重新生成前的聊天状态，并把原输入放回编辑框，可修改后再发。也可以编辑上一条用户消息，保存后点击重新生成；按钮在保存结束后自动恢复可用。
- 原消息、显示结果、MVU 快照、角色/全局/聊天变量、原流程账本及消息 extra、标题与时间、模式、深思和导演便笺直接从快照恢复，不重新运行 MVU 或请求模型。模型连接和主题、其他聊天不会被回撤改动。
- 整个平台只保留最新一个回撤点，保存在本机 Meowssiah-Data/备份/回撤/最近一次生成.json，不写进聊天或下一份快照，避免嵌套增长。下一次生成覆盖它，成功撤回后清除；重启仍可使用尚未消费的回撤点。
- 生成结束或停止后可撤回。普通发送撤回本次输入和回复；重新生成的回撤会找回替换前的回复。修改角色定义、世界书或预设后，旧回撤点会清除，避免跨不同运行规则恢复。
- 从本版首次发送/重新生成开始记录完整快照；此前的旧回复保留原样，不伪造缺失的生成前数据。

## 记住本机密钥

- 模型连接中可勾选“记住此连接的密钥（仅本机）”，重开后自动读取，无需重复填写。未勾选时仍只在本次运行中保留。
- 已记住的密钥使用 Windows 当前用户加密，存于本机 Meowssiah-Data/连接/密钥.json；不会进入普通设置、聊天导出或公开源码。文件适用于加密时的 Windows 用户。
- 按接口的协议、域名和端口隔离密钥；切到其他服务时不会携带上一服务的密钥。“清除密钥（含本机保存）”可一并清除当前服务的保存记录。
- MVU 继续使用正文同轮返回更新指令、本地计算的方式；本版没有增加额外变量模型请求，也没有改变原预设请求重写或历史滚动。

## 本地开发与自用

使用 Node.js 24：

```powershell
npm ci
npm start
# 需要时在自己本机生成程序
npm run build
```

上游源码和固定版本在 upstream/、integrations/，已生成的运行库在 app/；重新生成可用 npm run build:runtime。日常备份和维护方法见 [DEVELOPMENT.md](DEVELOPMENT.md)。

## 不进入仓库的内容

个人聊天、导入角色卡、世界书、连接配置、模型密钥、测试副本、依赖缓存和安装包都留在本地，不纳入 Git。Meowssiah-Data 是个人存档目录，更新代码或生成程序时应保留。
